website-notifier

This repository contains a notifier configured to run via GitHub Actions on a January 2027 date. Edit config/config.json and config/subscribers.json to change the message and recipients.

To enable real email sending, add the following repository secrets: SENDGRID_API_KEY and FROM_EMAIL.

To trigger a test send manually, go to the Actions tab, open the "Send Scheduled Notifications" workflow, and click Run workflow (workflow_dispatch).

Workflow file: .github/workflows/send_on_date.yml
